# Project writing conventions

Write all project files in English, including documentation, source comments,
messages, generated reports, chart labels, and filenames. Preserve imported data,
dataset labels, proper names, and recorded numerical results without translation.
Keep conversational replies in the user's preferred language.

Do not overwrite completed experiment data or model weights. Give new runs unique,
descriptive output directories. Distinguish stress diagnostics from held-out
validation/test results and disclose training-data reuse explicitly.

## Sharing

Share the current report, study README files, selected PNG/SVG figures, small
result summaries, provenance and source code. Study `local/` directories preserve
historical working bundles and are ignored. Full run directories, training data,
weights, predictions, detailed local evidence maps and `output/` rendering files
are ignored as well. They remain available on the research machine.

Original evidence paths inside captured provenance remain historical identifiers.
The local reorganization ledger is
`_local_archive/project_organization_20261101/relocation_manifest.json`.

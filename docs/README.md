# Project Documentation

Start with [the final-report workflow map](WORKFLOWS.md) to choose the matching
Phase I, temporal, Phase II or discussion implementation.

- [Research index](research/README.md): findings, evaluation scope, selected CSV
  results and implementation entry points.
- [Code guide](code/README.md): source/configuration inventory and static imports.
- [Result catalog](research/RESULTS.csv): retained result paths, hashes and origins.

Final report documents and report-production intermediates are outside the active
repository. Local copies, exported figures, old drafts and evidence workspaces
are consolidated in the ignored `archive/` directory. Historical report-helper
source is documented in [analysis/report_tools](../analysis/report_tools/README.md).
